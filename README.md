# 山东省大学生数学建模竞赛C题

## 题目名称
“五一”五日自驾景点优选与行程规划

## 项目简介

本项目针对 2025 年山东省大学生数学建模竞赛 C 题，为“五一”小长假自驾出游的三口之家设计了一套完整的景点优选与行程规划方案。

文旅片区共有 10 个成熟景点，在位置、游览耗时、开放时段、喜好度上差异显著。同时，五一出行存在时段性道路堵车和景点入园排队等待等随机扰动。家庭每天从酒店出发后，可连续游玩 1~2 个景点，景点之间直接驱车前往，当日结束后统一返回酒店。

项目通过建立多维度评价模型、多目标组合优化、蒙特卡洛模拟等方法，依次解决了以下三个问题：

1. **景点特征分析与组合优先级研究**：从游览耗时、通勤距离、拥堵敏感度、喜好度四个维度综合评价景点，并挖掘可联动游玩的景点组合。
2. **基准行程设计**：不考虑随机扰动，以喜好总满意度、通勤效率、可行性为目标，优选景点组合并编排完整的 5 天时序行程。
3. **稳定性量化评估**：结合堵车与排队的随机规则，采用蒙特卡洛模拟评估行程可靠度，量化两类扰动的贡献度，并识别结构性薄弱点。

## 运行方式

所有脚本均包含独立的 `main()` 函数，可单独运行。

### 1. 问题一：景点特征分析与组合优先级

```bash
python problem1.py
```

**输出内容**：
- 10 个景点的四维得分详情与综合优先级排名
- 堵车敏感度与排队敏感度的子维度拆解
- 高/低优先级景点推荐
- 可联动游玩组合（Top 10），包含联动评分与推荐理由
- 备选景点池

### 2. 问题二：基准行程设计

```bash
python problem2.py
```

**输出内容**：
- 每个景点的综合价值得分
- 最优景点组合（5~8 个）及组合评估指标
- 5 天景点分组（每天 1~2 个）
- 行程评估指标（总喜好度、总行车时长、松紧均衡性）
- 详细的每日时间轴（按环节拆解）

### 3. 问题三-A：抗扰动行程调整

```bash
python problem3a.py
```

**输出内容**：
- 调整前后的行程对比表（出发时间、结束时间、游览时长变化）
- 每日风险暴露评分

### 4. 问题三-B：稳定性评估（蒙特卡洛模拟）

```bash
python problem3b.py
```

**输出内容**：
- 整体可靠度 R_total 与失效概率
- 逐日失效概率统计（超时、不达标、超负荷、当日失效）
- 扰动因素贡献度分解（Shapley 值风格）
- 结构性薄弱点分析

### 5. 可视化图表生成

```bash
python visualization.py
```

**生成的图表**（保存为 PNG 文件）：
- `景点四维雷达图.png`：前 5 名景点的四维特征对比
- `景点联动热力图.png`：10 个景点两两联动评分热力图
- `行程甘特图.png`：5 天行程的时间条带图
- `每日负荷对比.png`：每日总负荷（整装+车程+游览+就餐）对比
- `收敛性曲线.png`：蒙特卡洛模拟的收敛性分析

## 核心方法

### 问题一：四维综合评价模型

| 维度       | 权重 | 评分依据                         |
| ---------- | ---- | -------------------------------- |
| 喜好度     | 0.40 | 家庭喜好评分归一化               |
| 游览耗时   | 0.25 | 舒适时长 + 弹性系数（舒适−最小） |
| 通勤距离   | 0.20 | 距酒店距离 + 到其他景点平均距离  |
| 拥堵敏感度 | 0.15 | 堵车敏感(0.6) + 排队敏感(0.4)    |

**联动评分**：综合考虑地理邻近性（0.4）、时间兼容性（0.3）、类型互补性（0.15）、通勤效率（0.15）。

### 问题二：多目标评价筛选 + 贪心分组

- **枚举搜索**：遍历所有合法组合（C(10,5)~C(10,8)，共 637 种）
- **三目标加权**：喜好总满意度(0.4) + 通勤效率(0.3) + 行程可行性(0.3)
- **贪心分组**：基于联动评分将景点分配到 5 天
- **时序编排**：按固定耗时逐段计算，超出 21:00 时自动提前出发

### 问题三：蒙特卡洛模拟 + Shapley 贡献度

- **随机模型**：
  - 堵车延时：高峰 U(1,4)h，平峰 U(0,1.5)h
  - 排队时长：高峰入园 U(0.5,3)h，平峰 U(0,1)h
- **失效判定**：超时(>21:00) 或 游览不达标 或 超负荷(>22:00)
- **抗扰动策略**：错峰出发 + 压缩弹性景点 + 保持弹性景点
- **贡献度分解**：采用 Shapley 值风格，分别量化堵车与排队的边际贡献

## 模型评价与改进方向

### 优点
- 四维评价体系全面，避免单一指标片面性
- 全局枚举搜索保证景点组合最优
- 抗扰动策略显著提升可靠度（+21.62%）
- Shapley 值精确量化两类扰动的协同效应

### 不足与改进
- 当前采用每日 1 个景点的保守策略，未充分利用“每日最多 2 个”的灵活性
- 可靠度 85.01% 距 90% 目标仍有差距，建议通过深度错峰、景点替换、增加休整日进一步优化
- 可引入动态规划处理每日 2 景点场景，或建立马尔可夫链考虑扰动的时间相关性
